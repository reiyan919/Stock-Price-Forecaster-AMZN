# 📈 Stock Price Forecaster — AMZN

A machine learning project that forecasts Amazon stock prices using deep learning and statistical models.

## 🎯 Project Goals
- Learn from historical stock prices (1980–2025)
- Predict future prices (next 30 days)
- Compare deep learning vs statistical model
- Show uncertainty (confidence intervals) in predictions

## 📊 Models Used
- **LSTM** (Long Short-Term Memory) — Deep Learning
- **ARIMA** (2,1,1) — Statistical Time Series

## 📉 Results

| Model | RMSE | MAE | MAPE |
|-------|------|-----|------|
| LSTM  | 14.30 | 9.92 | 6.06% |
| ARIMA | 1.12  | 0.35 | 1.90% |

## 🛠️ Tools & Libraries
- Python, Pandas, NumPy
- TensorFlow / Keras
- Statsmodels
- Scikit-learn
- Plotly

## 📁 Dataset
Amazon Stock Prices 1997–2025 (OHLCV) from Kaggle
